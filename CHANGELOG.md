# Changelog

All notable changes to this project will be documented in this file.

## [1.0.5+6] - 2026-02-01

### Added
- **Localization Support:** Full support for English and Bengali languages with a dynamic language switcher in the settings.
- **Offline Recommendation System:** Personalized book suggestions based on user listening habits, genres, and author preferences.
- **Smart Media Player:** Added playback speed control (0.5x to 2.0x) and persistent position saving.
- **Library Management:** Complete overhaul of History, Playlists, and Liked audiobooks.
- **Background Audio:** Improved foreground service for stable playback when the app is in the background.
- **Download for Offline:** Ability to download audiobooks for offline listening.

### Changed
- **UI/UX Enhancements:** Updated home screen with a new recommendation section and improved hero animations.
- **Database Architecture:** Optimized local storage using Isar for better performance and data integrity.
- **API Improvements:** Enhanced YouTube streaming logic for better stability and lower bandwidth usage.

### Fixed
- Fixed notification icon issues in various Android versions.
- Resolved minor bugs in search functionality.
- Fixed layout overflows on smaller screen devices.

---

## [1.0.0] - Initial Release

- Core audio streaming from YouTube.
- Basic search and author browsing.
- Basic background playback support.
